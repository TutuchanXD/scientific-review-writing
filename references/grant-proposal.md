# 基金申请论证

适用于本技能范围内的科研基金、人才项目等申请。与主技能的起草、科学审阅、仅文风修订三种工作类型配合使用；文稿用途不增加修改权限。指南、模板、篇幅和用户指定版本优先，不预设固定章节或保证资助结果。

## 先确定主线和新增研究

围绕一个主要问题组织材料：科学目标为何需要这项研究，已有认识或方法停在哪里，本项目准备增加什么，采用何种观测或实验能够判断进展。复杂项目可以有多个相互关联的问题，但需说明它们如何共同回答主要问题。题目、研究内容和考核指标的范围应相互匹配。

申请人的全流程经历用于说明研究基础、不同环节之间的联系和实施能力。创新性落在具体的新认识、模型、测量或处理方法及其可检验作用上；只有材料支持时，才将环节结合本身作为方法贡献。不要为展示经历把协作任务都扩入本项目主线。

动笔前按需要整理以下关系，工作记录可以很短，不强制交付表格：

| 对象 | 需要明确的问题 |
|---|---|
| 科学需求 | 拟观测或解释的现象是什么，现有能力受到什么限制 |
| 已有成果 | 已解决什么问题，依据、输入和成立条件是什么 |
| 新增研究 | 尚缺哪项认识或能力，资助期内准备解决到什么程度 |
| 申请人贡献 | 具体提出、完成或牵头哪些模型、实验设计、分析或方法 |
| 团队条件 | 已有设备、数据、平台和协作人员分别支持哪些工作 |
| 验证办法 | 哪种结果支持改进，哪种结果会限制方法的解释或适用范围 |

前期结果已经接近目标时，解释新增研究所针对的未决问题，例如变化机理、空间代表性、不同工况适用性或科学信号恢复。已有结果与新增研究紧邻说明，避免重复展示一次达标结果，也不把尚未开展的研究写成已有能力。

## 背景与文献共同推出问题

一般性背景保留理解科学需求所必需的部分，把篇幅用于具体困难及其影响。文献应说明前人完成了什么、结论在什么条件下成立，以及本项目准备推进哪一步，不能只在段末堆放引文。

按主张选择并核验直接相关的原始论文、公开技术资料或正式要求。引文支持范围与句子一致；未找到相关研究不等于证明该领域空白。使用“首次”“尚无”等优先性主张时，须有相应检索范围、日期和比较对象的依据；证据不足时，直接陈述本项目具体提出或拟研究的内容。

内部记录、未发表分析和团队资料可以支撑前期研究，保留其可追溯位置。是否进入正式参考文献表服从本次要求，不以内部汇报替代对公开研究现状的梳理。已有软件包、平台或论文的名称不能代替对实际方法和统计过程的说明。

## 创新性以比较和验证展开

每项核心创新交代：已有做法或认识、拟改变的假设或新增的约束、由此可能获得的科学认识或能力，以及验证这一差异的办法。无需把所有创新压成相同句式，也不预设方法必然优于基准。

模型分解需说明各项的物理或统计含义、归一化约定及数据对它们的约束能力；数学上能够分项不等于实验已能分别测量。测量量包含多个物理过程时，区分直接观测与机制解释，说明独立测量或受控实验如何增加约束。某个过程更复杂或更易受环境影响，只能构成研究动机或待检验假设，不能据此判定它已主导观测变化。

对现有方法的不足，限定到具体实现、输入、预处理和适用条件。不要仅凭算法类别断言它不能处理某类误差。若新方法使用物理先验或定标信息，应比较加入与不加入这些信息时的效果，检验信息本身的作用。

公平比较按问题选择相同目标集合、输入数据、参考信息、随机实现或误报水平，明确真正改变的因素。探索性结果可以支持继续研究；目标集合或工况同时变化时，不将结果差异全部归因于某一因素。具体控制变量和比较方法以实际实验为准，不机械要求所有对照完全相同。

## 个人贡献与实施条件

用可核验的工作说明申请人能力，例如模型推导、实验方案中的具体设计、测量链路诊断、算法实现及其实际解决的问题。独立完成、牵头和参与按事实区分；既有团队平台与申请人新增工作分别说明。

共同实验交代设计、操作、光路或硬件、数据分析之间的实际分工。合作人员的重要作用应准确体现；不将团队成果全部归入个人，也不为强调团队而弱化申请人已有贡献。无关经历不必逐项罗列，前后研究经历以共同的科学问题或方法能力连接。

每项主要研究内容对应具体未决问题和可用实施条件。设备采购须说明改善什么测量能力；数据处理与仿真须说明约束什么物理量或验证什么科学结果。避免用任务清单代替研究方法。

## 目标、预算和验证相互支持

涉及定量探测或性能目标时，在起草目标段前按 [科学论证要求](scientific-reasoning.md) 核对“科学信号—总误差或探测能力—分项预算—测量与校正要求—验证指标”。目标值、设计分配、实测值、仿真结果和拟验收值分别管理；不同层次的数值不必相同，但关系必须明确。

事件数、有效采样、时间尺度、相关性、信号衰减及缺测会影响最终探测能力。检出阈值与检出率分别定义；不从某个分项小于阈值直接推出科学发现或任务目标必然实现。先核对公式和条件，再用一致的数值及舍入方式写入摘要、研究目标、表格和考核指标。未批准的数值仍作为建议或待确认项，不在改稿中变成承诺。

验证需能区分误差抑制与科学信号损失。适用时采用信号注入与恢复、空白对照、固定基准或已知真值的理想对照。独立验证说明数据按器件、位置、时段或批次怎样选取，哪些数据用于设计和调参，哪些保留作检验；相邻片段、共享参考和重复使用同一序列的相关性按实际情况处理。

统计结果保留估计顺序、重复单位和离散程度。论文、软件和数据等成果数量依据研究内容与资源提出，待用户确认；不得为增强竞争力补造样本量、置信要求或提高幅度。风险安排针对具体限制及替代办法，并说明仍可获得什么认识，不把未达到科学目标的结果改称已完成性能验收。

## 把审阅意见转成申请正文

审阅记录用于指出错误、证据缺口及待核实事项，申请正文用于说明已有发现、研究问题、方法及预期贡献。获准科学修订时，将确有必要的评审意见落实为相应论证；不原样搬入“不能据此认为”“不把某量当成另一量”等重复的自我提醒，也不写入“本轮改为”“沿用初稿”等改稿经过。

对于尚未覆盖的情况，可以直接说明现有范围和拟解决的问题；对于已观察到的不利结果或影响主张的限制，仍须报告其事实与科学影响。不得以未来工作替代当前关键证据。否定词不是禁词，概念辨析、可辨识性和未通过指标等判断依科学含义保留。仅文风修订中，无法通过局部改句解决的论证缺口单独列出。

## 图表与篇幅

整稿起草时同步盘点现有图表和文献。按论证需要安排科学需求、物理或测量模型、前期证据、拟开展工作等图示；每张图应说明哪个问题及支持哪项判断，不要求固定张数。

实施流程图表示任务顺序、输入输出、判断与反馈关系。既有性能结果放在前期结果图表中；内部待办和尚未统一的表述在交付前处理或列为待确认项，不混入正式流程。拟建装置与已有装置分清，引用或改绘图的来源和编号保持可核查。

篇幅受限时优先保留决定研究必要性、创新性和可行性的论证，压缩一般介绍和重复说明；不能以字数限制为由只留下强结论而删除成立条件。固定模板下调整信息分配，不默认重排章节。

## 定稿与审阅收敛

按主技能完成科学、语言和定稿一致性核查。将审阅意见落实到具体位置，区分科学错误、证据不足、表达问题和可选增强；新增研究内容、指标或责任安排须处于当前授权范围内。

独立评审按用户授权采用，默认不因使用本参考文件而启动其他模型。已有严重问题得到解决，剩余意见属于偏好或范围外增强时，记录处理理由并完成交付，避免反复改写引入新矛盾。Gemini 中文交接继续遵循主技能的手动提交、完整回传和科学保真复核要求。
